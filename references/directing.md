# 导演与视觉决策

## 1. 先理解，再切镜

先阅读全文，识别主题、章节、主张、解释、例子、转折、情绪和结论。镜头以完整语义为单位，边界只能选已有 SRT cue 的开始或结束时间。

每个语义段先回答：

1. 观众此刻要理解或感受到什么？
2. 静音看画面时，哪种关系能把这件事表达清楚？
3. 画面中什么会发生有效变化？
4. 镜头最终落在哪个可见结果上？
5. 下一镜继承的是人物、物体、方向、颜色还是意义？

以铺垫、态度、经历或感受为主要任务时优先 A-roll；以解释知识、概念、结构、关系、步骤、对比、证据或具体对象为主要任务时使用 B-roll。人物经历可以带出知识，图解也可以包含情绪，按本镜主要理解任务判断。不要为了形式上的 A/B 交替破坏语义；连续三镜以上同类画面写明解释收益，允许核心图递进与同维度比较保持布局。

A/B 依据叙事职责划分，先于工具选择。H3、HyperFrames、Remotion 均可用于符合其能力的 A/B 镜头；人物存在、画面是否动画、素材是否生成，都不自动决定职责。画风和情绪取自当前单片 DESIGN，不从上一案例继承。

用观众的主要理解任务判断叙事重心，再检查次要人物、文字和物件是否服务同一任务；不按语法主语或“谁拿着卡片”机械分类。人物/文字混合的判断见 [逐镜编排](design-system.md#逐镜编排)。

### 表达方式与元素选择

先决定理解任务，再选最少够用的元素和关系，最后决定变化、风格与工具。人物、知识文字/数字、物件/容器、关系标记、真实素材、环境是可选元素；它们不需要在每镜齐备。卡片是载体，横向并列是布局，逐项突出是变化，IP 是可选主体，HyperFrames/Remotion 是实现工具，不能用其中一项替代其他决策。

| 主要任务 | 优先考虑的表达 | 人物与运动的作用 |
|---|---|---|
| 准确列出几个要点 | 文字、列表或卡片，逐项突出后共览 | 阅读顺序已清楚时无需 IP；静止保持也可成立 |
| 比较、筛选、连接、替换或展示过程 | 图解/程序化动效，按需加入 IP 操作 | IP 的操作应使关系或结果更清楚；不是每次出现文字就指一下 |
| 经历、困惑、压力与选择 | 人物叙事 | 行动与反应服务处境，不凭空增加剧情或把观点演成必然因果 |
| 事实、引文、文献和纪录材料 | 原件、局部定位、出处与结论对应 | 先保证证据身份和可读性；IP 不遮挡证据，不用生成场景冒充原件 |
| 真实操作反馈、空间和尺度 | 录屏、过程视频、地图或必要场景演示 | 保留关键步骤/反馈/方位；不为字面配图而额外生成一段走动 |

三卡例子：并列要点可平铺并随旁白逐项突出；三个方案要突出比较维度和选择依据；连续步骤要表现结果如何进入下一步，而非只依次亮起。只有人物的挑选、搬运、阻碍或纠正能增加理解时才加入 IP。列表本身不是低质量，缺少内容关系和阅读设计才是问题。

先继承用户对 IP 的选择。已要求保留 IP 时，在全片安排主持、过渡或总结的实际职责，B-roll 逐镜决定引导、操作、反应或让位；不能因局部图解不需要人物而把整片 IP 删除。未指定 IP 时，再判断去掉它以后知识关系、注意力引导或操作原因是否仍同样清楚，收益不足则简化；导航或提示确有收益时可用局部手势，不强迫每镜发生物理接触。人物存在不能把普通场景表演自动提升为 IP 互动讲解。

### IP 互动讲解：从知识关系到动作

已确定 IP 有解释收益且使用范围获准时，用以下方法推导它对知识对象的操作；无人物图解也可采用其中的关系分析。此方法的跨文案、风格和工具效果仍待真实短片验证，不是固定镜头模板，不增加审核门。

1. 提取原文关系与边界：连接、筛选、比较、积累或承压各要说明什么？不能把相关性演成因果，把努力演成必然成功。
2. 找可见的物理机制：连接后传递什么、筛选后留下什么、负担增加后哪里受限。只选必要载体；隐喻还需长篇解释时，改用直接图解或真实证据。
3. 确定主体与对象：人物、装置和信息元素都可以行动；人物没有解释收益时不加入，不默认创造 IP。
4. 设计可展开的状态与结果：起始图保留待完成关系和操作空间；结果驱动镜头可设计完整尾帧。角色/风格参考不等于首尾约束，不强制所有图片都是未完成状态。
5. 按需要组织准备、行动、对象反应、后果与保持。它们是节拍内部细节，不机械拆成五个状态，不新增 narration_beats；顺序与时长服从原旁白。

先写一句“IP 对什么做什么，使观众看见什么关系”。若只能写出走路、摇头、指卡片或展示情绪，还须检查知识关系是否真正被解释；情绪有价值时归入人物叙事，不冒称 IP 互动验证。角色保持其身份，不能为了表演而冒充历史人物、证人或专业权威。学习参考项目的推导方法，不默认继承其角色、构图和动作组合。

### 同一动作的连续、定格与程序化实现

连续表演检查运动路径、接触、对象反应和身份稳定；定格/剪纸拼贴允许用关键姿态跳变、省略中间动作，检查前后对象归属、动作方向、遮挡与落点可读，不能强制补帧或自然平滑。重量与反应可由姿态、位移幅度、停顿和必要音效表达；不能把意外卡顿解释成定格。Vox 式参考需拆成具体材质、节奏和阅读方法，不把风格名称当统一动画算法。

精确文字、数字和卡片关系由 HyperFrames/Remotion 等排版与动画工具控制；IP 可用透明状态图、分层素材或按需生成的视频参与同一镜头。先确定谁操作哪个对象、对象怎样回应，再决定锚点与遮挡；不是把 IP 动画贴在独立播放的卡片旁。静止足以解释时保留阅读时间，不为使用工具增加动作。

用现有 `visual_design.relation/carrier/character_role/motion_intent`、`changes` 与 `final_state` 表达决定；风险放入 `risk`，缺口放入 `production.asset_gap`。不建立第二份逐镜时间真源。七列表格用自然语言写清“谁做什么、什么改变、为何帮助理解”。

出图前规划动作意图，出图后按实际姿态、握持、道具、接触与空间校准动作。图片不支持核心表达时改图或复核方案，不凭空添道具、不靠运动纠正错字，不为迁就图片删掉原意。执行见 [实际图片到动作提示词](comfyui-video-production.md#实际图片到动作提示词)。

参考：[Ian 小黑的原创隐喻方法](https://github.com/helloianneo/ian-xiaohei-illustrations/blob/main/ian-xiaohei-illustrations/references/composition-patterns.md)。只吸收概念转物理关系的思路，不依赖其 Skill、角色或案例资产；连续动作的实现效果仍须本项目实测。

## 2. 主画面 A

A 画面承担讲述者、情境和情绪。

可采用生成式连续视频、程序化/分层动画、状态序列或有理由的静止，按本镜动作与节拍选择；固定人物微场景和完整 AI 场景均支持视频。两种主画面模式约束人物与视觉世界，不要求全片使用同一种运动方式。

固定人物模式为每镜标记一个 `a_view`：`presenter`、`protagonist`、`supporting` 或 `first-person`。这是构图视角，不是四套角色或四种画风。

### 固定人物微场景

- 一个固定人物贯穿全片；只有用户明确要求时才将其作为 IP 设计和使用；
- 人物通过动作、姿态、表情、道具和环境关系表达内容；
- 先锁定五官、头身比例、体型、服饰、配色、线条和阴影规则；
- 只有一张已授权的人物身份参考图且确实需要固定身份时，先做三视图和细节规范，再生成镜头资产；不因画面需要人物就自动创造 IP；
- 主持人、主角、配角和第一人称只是构图视角，不是四套人物风格。

### 完整 AI 场景

- 每个镜头是一幅完整场景，不要求固定主角；
- 全片锁定配色、材质、线条、光线、人物表现和场景复杂度；
- 重复人物或标志性物体仍需使用同一规范和参考资产。

### 封闭构图

- 主体居中或视觉重心稳定，动作和因果关系在画布内闭合；
- 关键人物、手脚、道具、符号、运动线和环境线完整收在画布内；
- 默认让所有有效绘制痕迹距资产边缘至少 8%，除非镜头规范另有经过验证的安全值；
- 背景提供必要情境和层次，不抢主体，不依赖画外空间才能理解；
- 给轻微推拉、平移和外部字幕留余量；不同画幅分别出图或重新构图，不硬裁。

长 A 镜头按旁白需要安排发现、犹豫、选择、行动或结果，不按时长强制状态数量。单状态填写 shot.static_reason，说明保持期间为何仍与旁白对应；每个计划状态绑定原始短语和准确时间。Slow Push、呼吸、眨眼与背景循环不代替内容变化。

## 3. 信息画面 B

B 画面承担概念、定义、因果、流程、层级、组成、对比、证据和真实对象。

素材类型 `material_type`：

- `verified-media`：用户提供或已经核实的截图、录屏、图片、数据和案例；
- `no-material`：卡片、关系图、流程图、图标和可视化结构，`presentation_type=infographic`；生成式解释场景使用 `presentation_type=scene`，不得冒充真实证据；旧 `screen_subtype=diagram` 不作为素材类型；
- `text-only`：章节、金句或结论，克制使用。

B 可作为包含角色互动的独立 composition；人物负责指示、操作或回应信息时，仍以信息关系为主。人物与文字同屏按完整镜头设计，禁止未经编排、与叙事无关的浮层叠放，不禁止有意义的分层合成。动画只保留语义变化：元素出现、重点选择、关系建立、方案比较、步骤推进和结论落定。背景循环、装饰粒子和逐字字幕出现不能代替知识变化；新条目、命名、关系或结论的建立属于信息变化，即使用简单显现实现也可以成立。阅读保持本身无需增加新变化。

每个 B-roll 语义段先选择一个具体 `visual_structure`，用空间关系直接表达本段含义。统一视觉系统不等于统一布局：配色、字体、材质和标注语言可以复用，列表、三卡、左右分栏等结构骨架不能成为所有知识段的默认容器。判断结构是否相同，要看主体关系、阅读路径和核心动作，而不是名称是否不同。

构图先落实单片 DESIGN 的文字边距、字幕区及物件安全区，再设计视觉重心、对齐线和阅读路径。独立标题、证据与出处按画面网格组织；门柱、木牌等物件上的文字按物件自己的可贴面定位。画面元素即使全在安全区内，若标题、主图、解释文字互不归属或重量失衡，仍需重新排版；见 [安全区与布局](design-system.md#安全区与布局)。

计划中的每一次 B-roll 信息变化都通过 `narration_beats` 绑定原始 cue 起点与逐字短语，生产时原样进入 `motion_sequence`。模板自己的默认时间只能做 easing 和阅读期，不能覆盖旁白触发点。

A/B 共享当前 DESIGN 的字体、颜色职责和图形语言；verified-media 保留素材原色。职责由内容与编排判断，不靠固定明暗配色。角色互动与布局让位规则见 [design-system.md](design-system.md)。

## 4. 信息动效模板

先按 [视觉表达选型](broll-expression-selection.md) 写清主体关系、核心动作、阶段与不变量，将简报通过 `--expression-brief` 传入 `scripts/select_broll_template.py`。动作优先，语义结构、信息项数量、可用时长和画幅辅助判断；动作相关但容量不符的候选保留为适配参考。主 `semantic_structure` 仅用 `comparison`、`aggregation`、`filtering`、`hierarchy`、`causality`、`replacement`、`expansion`；流程、时间线和组成关系写入 `semantic_pattern` 或 `secondary_structures`，不新增主结构值。

选模板前对照最近三个 B-roll 的结构签名，作为重复提醒而非禁用窗口。允许核心图递进、同维度案例比较和概念回顾，在 broll_structure_exceptions 记录语义理由及内容推进或回顾用途。布局可以不变；机械换字换色又无解释收益才需返工。

模板命中时只替换内容、合适素材和必要视觉 token。没有合格命中时，先跨语义类别检查动作相关的外部候选，不得以“从零实现更快”为由跳过。逐镜读取具体镜头卡和演示；候选为 `available` 时继续读取对应实现文件，再核对元素关系、主要动作和阶段顺序。初轮不适合或目录为空，都须用至少两种动作查询覆盖两个来源扩大搜索；仍无合适来源，再逐项说明实际检查候选的拒绝理由并记录吸收的运动原则，才允许新建模板。公开可见不等于允许复制：未检测到许可证时只做抽象结构研究。

详细记录格式和验证命令见 [B-roll 外部骨架研究门](broll-external-research.md)。静态 SVG 可以作为动画组件，不能单独证明信息动效已经完成。

每个模板必须记录 ID、语义结构、适用内容、信息项范围、时长范围、画幅、字段、动画阶段、预览、技术来源、许可证、可用状态、验证状态和已知限制。

## 5. 视觉编排字段写法

每个镜头至少写清：

- 镜头编号、开始与结束时间、覆盖的 SRT cue；
- 原字幕和观众要理解的一句话；
- A/B 职责及子类型；
- 主体、构图、景别、动作、表情、道具或信息元素；
- 按旁白顺序发生的有效变化与最终画面；
- 与前后镜头的视觉或意义衔接；
- 所需素材、来源、真实性风险、制作难度；
- 动效方式、主制作工具、选择依据和回退；信息图镜头另列模板 ID 或新模板需求。
- B-roll 的具体 visual_structure、选择理由及与相邻段共同推进解释的方式；

原字幕保持逐字一致。真实素材缺失时写 `needs-supplied-material`，不得用生成内容冒充。

`changes` 与 `narration_beats` 是同一组导演决定的两个视图：前者描述画面发生什么，后者描述由哪段原始旁白在什么 cue 起点触发。二者按位置一一对应；旁白节拍不得自行改写短语或脱离 SRT 填写估算时间。

### 相邻镜头怎样交棒

分镜时逐个检查接缝，先写出前镜的落点、后镜的起点、两者共享的对象或意义，以及旁白是否留有换景空间。`from_previous` / `to_next` 不能只写“自然过渡”；需要说明观众的视线从哪里去到哪里。转场负责**换观看位置**，不能代替镜头内部的证据展示或内容变化。

按这条顺序选：

1. 对象或关系需要立即对照、论证正在推进时，先试直接切；保持共同的屏幕位置、运动方向或音频连续性即可。
2. 两镜共用真实可辨的物件、局部或容器时，可试同物接力、穿窗或运镜接续。放大的原件必须有足够清晰度，后景应确实是它引向的内容；不凭空把不相关图像伪装成同一物件。
3. 纸感、光线和情绪相近，但空间从近物转为远景时，可试短叠化、焦点接力或经由共同底材接力。共同底材法让前镜退回已有纸色/空间，再让后镜从同处显出，不同时叠两套文字；中段若像白闪或断片，应缩短留白或改为干净切点。短叠化若产生双重文字、人物或轮廓，也不能因为“柔和”就保留。
4. 章节或时间大跳跃需要明显停顿时，才用翻页、题签或短暗场；它要承担章节信息，不做每镜固定包装。

转场时长从相邻镜头可用的停顿和阅读保持中取得，不挪动原旁白与 SRT 边界；一个接缝只用一种主动作。最迟在下一句有效信息开口前让新画面稳定。用真实素材做短预览，检查转场前、中、后和正常速度播放；字幕、出处和数字不能在混合帧里形成错误阅读。若转场只让画面更忙，保留直接切。

## 6. 全片复查

- 每个镜头是否明确帮助理解或感受？
- A-roll 是否在讲人，B-roll 是否在讲知识或信息增量？
- 是否连续重复同一职责、构图、视角或动效结构？
- 对照近邻和跨段核心图，复用是否服务于递进、同维度比较或回顾？是否只有换字换色而无解释收益？
- 是否有长时间无有效变化或短时间信息过载？
- 是否提前表现后文结论，或继承了无意义的上一镜道具？
- A/B 切换是否由语义驱动，并有方向、颜色、物体或意义上的承接？
- 需要转场的接缝是否有明确视觉锚点或语义作用；中间帧有无文字重影，下一句开口时新镜头是否已稳定？
- 是否存在未经文案授权的推断、数据、产品细节或案例？
- 所有文字是否能在目标画幅和可用时长内读清？
