# 动作音效

用于分镜中的关键动作、资产组装和声音验收。默认按需加入简单动作音效；BGM、持续环境声和复杂声音设计仍按用户要求添加。用户要求无音效或仅保留原声时优先执行。旁白保持原文、原速和时间，不为配音效移动 SRT 或伸缩主音轨。

## 1. 分镜阶段

- 先判断声音是否能强化动作的重量、材质、因果或结果，再决定是否添加。碰撞、落地、机械启动、盖章等是候选，不是每镜必选项。
- 在对应 `changes[].event` 的动作描述后注明声音意图，例如“纸箱落桌，配短促空心碰撞声”；同步对应 `narration_beats` 的状态描述及实际使用的动作提示词实例。沿用现有八列表格，在“动态变化”中显示，不新增旁白节拍或独立音效列。
- 需要的音效素材记入镜头 `materials`，说明声音类型、对应动作和来源是否待定。没有必要时保留安静，不为每次文字出现、每个转场或每一步动作配声。
- 规划阶段可以只标明“接触时响”，不要把 cue 起点冒充实际碰撞时刻。精确位置待动作成形后确定。

## 2. 选材与制作

- 按画面材质和情绪选音色：纸张轻脆、木头空心、金属清亮；同类物件保持一致。夸张程度跟随项目风格，不把本片的卡通音色固化为所有项目默认。
- 优先复用项目中合适且可用的素材；新增素材记录实际文件、来源及使用条件，生成音效记录实际工具与提示词。搜索关键词和推荐清单不算完成素材。
- 以实际动作的接触、启动或落定帧为同步锚点。考虑素材自身的静音前导和起音位置，把声音的有效瞬态对到动作上，而非只把音频文件开头对齐。预备动作可有短前导声，但主撞击必须跟随接触。
- 在主时间线独立音轨放置，保留可调音量、裁切和必要的短淡入淡出。优先使用不含重复音效的镜头资产；已有源声音先盘点，避免二次叠加。
- 旁白优先。根据实际素材响度调低音效，尤其避开关键词；不以统一音量百分比代替试听。连续脚步、机械声只保留有叙事作用的部分，主要撞击与次要动作拉开轻重。
- 沿用已授权的制作范围和审核模式，不新增逐音效审批。素材不可用时登记缺口并继续无依赖工作，不静默省略已经计划的关键音效；新增计费仍按实际授权处理。

## 3. 验收与记录

- 先静音看动作，确认主体、对象和结果本身可读；再带旁白听样片。音效不能掩盖动作实现不足。
- 回放实际导出，逐项检查计划音效是否出现、主瞬态是否卡准动作、材质和力度是否合适、旁白是否清楚，以及是否存在过密、重复、削波失真或裁切爆音。
- 在现有时间线审计和 QA 报告中记录对应镜头、动作、素材路径/来源、实际音轨与实例、同步锚点、音量处理及试听结论；没有独立实例时如实记录源文件内声音。未能试听则标记未验证，不以文件含音轨或峰值检测通过代替听感验收。
- 改动作时重查关联音效；改混音或重新导出后，检查新文件的声音及适用的整片导出 QA。是否添加 BGM 与是否完成动作音效分别说明。

本次为文档执行规则，沿用既有字段，不新增 JSON 必填字段或脚本校验门。现有校验通过不能代替上述人工声音检查；旧项目按本次续做范围补齐，不自动修改历史素材、哈希或批准记录。
