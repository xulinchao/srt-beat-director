# 知识分享与读书稿：表达选型

用于这两类内容的分析、分镜和视觉基线。这里的 A/B 是本 Skill 的功能分工，不是通行影视术语的重新定义。字段以 contracts.md 为准。

## 先判断内容职责

按“理解点 → 功能 → 主体关系 → 载体 → 必要动作 → 风格适配”编排。解释、例证、强调、导航和氛围可交叉，不是固定密度等级；例子不自动成为证据。方法/概念着重机制、条件与操作；观点/方法读书稿分清作者、理解和实践；文学/故事着重处境、关系、行动与情绪，不一律图表化。

人物可以成为 B-roll 的展示者、指示者、操作者或承载者。是否出现由解释收益决定，信息密集时缩小、移侧、改头像/手部或退出。详细编排和生产路径见 [设计与角色互动](design-system.md)，不把动作示例固化为信息类型模板。

在既有 viewer_takeaway、visual_design、changes 和转场说明中写清本段是问题、观点、引文、解释、案例、实践还是总结，以及选择画面的理由；不必新增固定分类字段。

- 知识分享优先围绕具体问题、原因、方法、应用及边界组织。
- 读书稿区分作者原话、准确转述、创作者理解和个人实践。引文记录书名、作者、版本及页码或章节；来源缺失时请求补充，不生成假书页、假引文或伪造经历。
- 上述是选型线索，不是固定叙事顺序。不改已有 SRT，不为凑 A/B 比例或视觉类型重写文案。

## A-roll：人物处境

固定人物模式优先“人物＋必要道具＋简洁微场景”。保持身份与视觉系统，通过处境、视角、景别、姿态和人物关系变化，不让书房桌前成为所有经历的默认背景。

- 困惑：明确动作对象和阻碍，例如手停在录制键前。
- 尝试：呈现操作与反馈，不只拿着道具摆拍。
- 情绪转折：起始与终态有可辨认的视线、姿态或表情差异。
- 帮助与交流：用双方注意力和动作关系表达，不靠角色数量凑丰富。
- 开场、过渡、总结：可用直接面向观众的主持人视角。
- 具体环境或氛围确有意义时保留完整场景；白底、暖纸色或全屏图片均不是独立的 A/B 类别。

动作数量由语义节拍决定，不再按秒数强制两张或三张图。单一处境可以稳定保持，但须在计划 shot.static_reason 说明为何足够、保持期间旁白如何仍与画面对应。single-state 只落实一个计划节拍，制作实例继承同一理由；多个计划状态必须全部落实，不能借静止理由删减。呼吸、眨眼、推镜不替代内容变化。

## B-roll：关系与证据

| 内容关系 | 候选布局 | 误用检查 |
|---|---|---|
| 并列、分类 | 分组、矩阵、集合 | 并列项不要画成因果箭头 |
| 对比 | 同维度双栏、共享基准 | 两边维度与尺度是否一致 |
| 步骤、时间 | 路径、步骤推进、时间线 | 先后顺序不自动代表因果 |
| 因果、条件 | 因果链、分支、反馈 | 原文是否支持因果和条件 |
| 层级、组成 | 树、嵌套、拆解 | 从属关系不等于重要性排名 |
| 筛选、选择 | 条件筛选、候选收敛 | 条件和淘汰依据是否明确 |
| 变化、替换 | 同对象前后状态 | 保持比较对象一致 |
| 循环 | 闭环、反馈路径 | 是否确实回到前一步 |
| 原文、证据 | 真实摘录、局部标注 | 可追溯，不用装饰图冒充证据 |
| 数据 | 与变量匹配的图表 | 没有真实数值就不用雷达面积或精确坐标伪装量化 |

这是设计候选，不新增 semantic_structure 枚举；继续用既有七类，细分写入 semantic_pattern 和 visual_structure。桥、天平、雷达仅在隐喻准确时采用，不作为必用模板。

允许核心图跨段发展、同维度案例重复比较、结尾回顾原图。对照最近三个 B-roll，审查复用的解释收益，不以重复本身否决；详见 SKILL.md「核心制作约束」。复用时在 broll_structure_exceptions 记录对应镜头、semantic_reason、visible_difference；后者可描述新增节点、重点变化或“布局保持不变，用于回顾已讲结论”，不强制换布局。跨更长区间的回顾也记录。机械换字换色却没有解释收益应返工，不能靠填字段代替视觉判断。

## 节奏、参考和验收

固定人物、字体、配色、线条、标注和安全区；不固定 A/B 比例、每镜时长、结构数量或动作数量。先建立，再按旁白突出关系，最后留阅读时间。字幕保留，信息图避免另放一整份逐字稿争抢注意力。

截图参考登记为风格、布局或动作参考，并说明吸收什么、舍弃什么；截图不能证明动画节奏。先做包含人物情境、解释图和原文/案例的代表样片，不因某次改版受欢迎就把其中的桥或雷达固定为全局风格。

人工 QA 核对：人物处境是否清楚、背景是否多余、缩小到目标观看尺寸后情绪和文字是否可读、图形关系是否准确、复用是否帮助理解、作者与创作者观点是否分清。程序只检查结构和证据完整性，不能证明这些判断。实际导出同步和黑闪仍执行 qa.md，不以编辑器预览代替。
