# 道系青年 · 纸感手绘与深绿网格

状态：v0.1，30秒样片的视觉与技术链路已验证；最终画法、听感与新话题泛化待验证。此预设服务于“输入不同文案，设计对应画面”，不提供固定视频的照抄分镜。角色身份、画面风格和本次文案分别输入。风格分析覆盖全片约240.73秒，样片制作范围为前30秒；见[全片风格证据与画面语法](REFERENCE-ANALYSIS.md)及[验证范围](VALIDATION.md)。

## 稳定的视觉语言

| 项目 | 规则 |
|---|---|
| 纸感场景 | 暖米白纸纹、细石墨轮廓、低饱和鼠尾草绿与灰蓝；背景比主体更淡，光影轻，避免复杂动漫渲染 |
| 信息画面 | 近黑深绿网格；灰白中文文字；绿色只标当前重点、关系或完成状态；薄边线，克制圆角 |
| 人物 | 使用已选道系青年参考；黑碎发和弯呆毛、普通耳朵、松弛灰眼；灰蓝短道袍、交领、腰带与棕葫芦 |
| 构图 | 一镜一个理解点；人物与核心道具形成视线、指示、操作或反应关系；四周收住关键手部、道具和线条；留字幕区 |
| 动作 | 先按文案确定需要建立、改变和结果的状态；定格状态也可成立，连续表演按需制作；不以慢推替代语义动作 |
| 文字 | 准确正文、标题、数据在排版工具与主时间线制作；GPT图不承载必须准确的中文长句 |

人物出现、深浅背景和A/B身份不是同一件事。根据观众主要理解任务决定职责；人物可以操作概念，信息画面也可以有人导航。

## 每次换文案的设计步骤

1. 提取这段文案的理解点、情绪和旁白触发短语。
2. 决定主角是人物处境，还是概念/证据/关系。
3. 为这次文案选择具体载体：选择可以是路口，犹豫可以是两件道具，方法可以是流程纸。按[全片语法](REFERENCE-ANALYSIS.md)匹配分栏经历、第一视角取物、清单筛选、关系汇聚、时间轴等表达；不用所有文案都配电脑、书房或内容墙。
4. 写清主体、道具归属、视线/接触、初始状态、变化和结果，再套用本预设的画法与色彩。
5. 状态数服从意义。新图继承同一身份；第二状态优先编辑首状态，保证场景、机位、道具一致。
6. 以新文案检查可读性、同步与身份；已通过的风格不能替代新镜头QA。

## 通用出图模板

使用时先读[参考用途索引](reference-index.json)。角色身份采用 [已选角色](references/dao-youth-approved.png)；画法参考可用[源片纸感样张](references/paper-style-source.jpg)，只继承线条、色块、材质和背景层次。它的第一视角、抽屉和手势不随参考迁移。自产[流程场景](examples/a-workflow.png)、[思考场景](examples/a-thinking.png)和[信息画面](examples/b-shared-method.png)用于核对候选效果，其细节差距见分析，不自动成为所有镜头的构图模板。

```text
输入参考1：本角色身份，只约束人物；输入参考2：本风格样张，只约束线条、上色、材质和环境层次，不沿用其机位、道具或动作。

文案：<本次真实原文>
观众理解点：<一句具体目标>
画面职责：<人物处境/概念解释/导航/证据>
本镜主体关系：<谁在看、拿、指、选择或操作什么>
本镜场景和构图：<根据当前文案设计，不复制样张场景>
状态：<建立/变化/结果及必要动作；每次只生成一个实际状态>

画法：暖米白轻纸纹，细石墨轮廓，低饱和色块，轻阴影，淡环境；保持主体姿态清楚、手部自然、道具完整。头发用少量整体分组，不画大量细发丝；道袍大色块，不增加云纹/暗花；环境不过度渲染写实日光、投影与景深。
角色：使用身份参考中的道系青年，不继承风格样张的其他人物。
规格：<当前画幅与分辨率>；关键元素收在画布内，底部<字幕安全区>。
准确中文与字幕由后续排版/主时间线制作，此图不含字幕、水印、镜头编号。
```

## 风格与参考的边界

参考作者视频用于提炼视觉语言；本次前30秒原文、原声与原字幕只是风格测试输入。它们不自动成为后续作品的脚本、声音或镜头资产。样例中的电脑、流程纸和内容墙不构成场景白名单。

出图必须调用内置GPT；不可用或调用失败即停止整个工作流并提示，不自动替换生成工具。

在新视频任务中按本页规则形成单片 DESIGN，把实际使用的身份/风格图复制到该任务 input/references 并登记用途、哈希。按新文案选择语法、生成逐镜提示词，依当前 Skill 进行 QA；不照搬本次样片的分镜或字幕资产。本预设为明确选择后的可选方向，不自动覆盖其他视频的画风。
